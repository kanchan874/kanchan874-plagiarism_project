How It Works

01

Upload

Drag and drop or browse a TXT, PDF, or DOCX file up to 5 MB.

02

NLP Pipeline

Lowercasing → Punctuation removal → Tokenisation → Stopword removal → Stemming.

03

TF-IDF Vectorisation

Text is converted to TF-IDF feature vectors using bigrams for richer context.

04

Cosine Similarity

Cosine distance is computed against every file in the dataset corpus.

05

Sentence Matching

Individual sentences are matched to find exact and near-exact lifted passages.

06

Report

A detailed report shows the similarity %, matched file, and highlighted sentences.
